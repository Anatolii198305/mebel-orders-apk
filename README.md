# Перетяжка — релизы Android

В этом репозитории публикуются готовые APK приложения «Перетяжка».

## Как установить

1. Откройте раздел **Releases**.
2. Скачайте последний файл `mebel-orders.apk`.
3. Откройте его на телефоне и разрешите установку.
4. Приложение установится поверх старого, данные сохранятся.

## Автообновление

В приложении на странице «Синхронизация» нажмите
**«Проверить обновление»** — новая версия скачается с GitHub
или с компьютера по Wi‑Fi.

Тег релиза должен быть числом версии: `v4`, `v5`, `v6` и т. д.
